* **Inference Optimization**: Distilled diffusion and video transformer tuning. Optimized **LTX-Video 2.5** inference by **×2.1** on RTX 4090/5090 hardware (NVFP4 mixed quantization, Gemma 4 Heretic TE, reduced 6+2 sigmas, resident VRAM scheduling).

* **Polyglot Microservices**: High-performance backends in **Python (FastAPI, PyTorch)**, **Node.js / TypeScript**, and **Go / C++**.
